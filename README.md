# OGS Simple Modeling Workflow

This repository contains a reproducible workflow for simplified subsurface flow modeling using OpenGeoSys (OGS), Gmsh, and Python.

The repository is intentionally structured as a simplified benchmark workflow that can later be expanded toward more realistic subsurface numerical modeling applications using fully open-source tools.

The project demonstrates a structured notebook-based workflow for:

- Geometry and mesh generation in Gmsh
- Boundary and submesh extraction
- OGS project file generation
- Numerical simulation of fluid flow

The workflow integrates:

- Gmsh for geometry and mesh generation
- Python notebooks for workflow automation
- OpenGeoSys (OGS) for numerical simulation
- ParaView-compatible outputs for visualization
